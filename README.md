Beta Deco
==========================================================
Port of content from several Beta 1.7.3 mods. Includes:
1) Kaevator's Wallpaper: wallpaper decoration entity
2) Deko-Mod: window (half-door-like) block
3) Rope mod: climbable rope block

Kaevator's Wallpaper
----------------------------------------------------------
A ItemFrame-like entity that can be placed on solid block
face (eg full block, back of stairs block etc.).
1) Crafted from paper and wool.
2) Right-click wallpaper entity with wallpaper item in hand
   to forward cycle through wallpaper variants.
   Crouch-right-click to cycle backward.
3) Wallpaper item remembers last wallpaper variant selected
   (current variant is shown in the item tooltip)
4) Right-click wallpaper entity with a dye to apply color.

Deko window
----------------------------------------------------------
Door-like translucent block. Right click one window in a
vertical row of windows to open/close the entire row.

Rope
----------------------------------------------------------
Chain-like climbable block. If rope is placed vertically
right-click it with rope item to lower the rope (place block
bellow entire rope column).

Mod is in Beta
----------------------------------------------------------
Things might break and are a subject to change! Always
remember to make backups of your important data.
